Mode d'emploi

DémarrerCarteFicheSynchroniserOrganisation

1. Démarrer

  1. Installez l'appli : menu ⋮ (ou Partager sur iPhone) → Ajouter à l'écran d'accueil.
  2. Touchez Activer en haut et autorisez la localisation.
  3. Le bandeau devient vert dans le secteur 220, rouge dehors (le téléphone vibre quand vous sortez). Il indique la distance jusqu'à la limite.
  4. Onglet Bilan : saisissez le nombre de calendriers reçus pour suivre le stock.
Tout fonctionne sans réseau. Les saisies restent sur ce téléphone, même si vous fermez l'appli.

2. La carte

  • Touchez un point (ou juste à côté) pour ouvrir sa fiche. Zoomez pour séparer les points serrés.
  • Couleurs : à faire · fait · repasser · immeuble en cours · refus · inaccessible.
  • Les gros points sont des immeubles ou résidences (plusieurs logements).
  • Les zones 1 à 5 sont délimitées en tirets avec une teinte légère. Le bouton Z les affiche ou les masque.
  • ◎ recentre sur vous · ⌖ ouvre l'adresse non faite la plus proche · ＋ ajoute un point oublié à votre position · 🗺 affiche le fond de carte détaillé (réseau nécessaire).
  • Onglet Adresses : la liste par zone et par rue, avec les filtres « À faire », « À repasser », « Près de moi ».

3. La fiche adresse

  • ✓ Fait : pour une maison, compte 1 calendrier et ferme la fiche. Ajoutez le montant avec +5, +10… et le mode de paiement.
  • Absent · repasser : laissez un avis de passage, l'adresse passe en orange.
  • Immeuble : utilisez « Logements faits » (ex. 3 / 12). Il passe en vert quand tout est fait.
  • Note : n° réel si « bât. sans n° », code portail, horaire pour repasser…
  • Erreur ? Remettre à faire efface la saisie de l'adresse.

4. Synchroniser avec le binôme

Chaque téléphone garde son propre suivi. Pour avoir les mêmes infos sur les deux, on s'échange un code. À faire à chaque fin de tournée, ou dès que vous vous séparez.
  1. Téléphone A : onglet Bilan & binôme → Envoyer mon suivi.
  2. Choisissez WhatsApp ou SMS et envoyez le message au binôme (il contient un code qui commence par S220:).
  3. Téléphone B : copiez tout le message reçu (appui long → Copier).
  4. Dans l'appli : Bilan & binôme → collez dans la case « Collez ici le code reçu » → Fusionner le code collé.
  5. Faites ensuite l'inverse (B envoie, A fusionne) : les deux téléphones sont identiques.
  • Pour chaque adresse, la saisie la plus récente gagne. Rien n'est effacé.
  • Vous pouvez fusionner plusieurs fois le même code sans risque.
  • Si « Envoyer » ne propose pas WhatsApp, le code est copié : collez-le dans un message.

5. Organisation conseillée

  • Une zone par sortie (1 h 30 à 2 h), de la zone 1 à la zone 5. La liste suit les rues dans l'ordre des numéros.
  • Un trottoir chacun dans les rues (pairs / impairs), ensemble dans les résidences.
  • Meilleurs créneaux : samedi 10 h–12 h, semaine 17 h 30–19 h 30.
  • En fin de tournée : filtre « À repasser », puis synchronisation et contrôle caisse = total du Bilan.
